# Bahan asis SignalGen — 4 November 2026

Pemeriksaan implementasi dilakukan 2 November 2026. Dokumen ini membedakan
hasil fixture, pengujian lokal, dan smoke test layanan asli. Target demonstrasi
adalah web multi-user Model A; legacy Claudio dan simulasi portofolio tetap ada.

## Yang dapat didemokan

| Bagian | Hasil dan bukti | Batas |
| --- | --- | --- |
| Analisis semua sinyal | Setiap sinyal independen, close acuan, O/H/C T+1…T+n, BUY/SELL, TP/SL, ringkasan serta CSV | Tidak mengeksekusi order dan tidak menjumlahkan return menjadi return portofolio |
| Seluruh katalog | Konteks membekukan katalog/rule; batch 10, satu worker, progress, cancel, retry hanya kegagalan | Fixture 23 saham/3 batch; belum membuktikan pengambilan seluruh katalog Yahoo tanpa kegagalan |
| Penyimpanan hasil | Detail dipaginasi dari IndexedDB; uji kuota rollback dan ekspor hasil parsial | Batas aplikasi 128 MiB per akun; hasil studi sementara, bukan jurnal permanen |
| Jurnal | CRUD manual tetap; checklist Match menuju review, konfirmasi, UUID stabil dan retry gagal saja | Pengujian penulisan memakai fixture; akun asli tidak diisi transaksi fiktif |
| Loading | Health outage direproduksi; hasil lama dipertahankan, GET identik digabung dengan pembatalan per pemanggil | Gangguan cloud/provider tetap dapat membuat data belum diperbarui |
| Kompatibilitas | Portofolio next-open dan arsip lama tetap; native/WASM parity dan batas private evaluator diuji | Tidak mengklaim seluruh perilaku Claudio identik |

## Pembagian kerja

```mermaid
sequenceDiagram
  participant B as Browser
  participant S as Backend Go/Gin
  participant D as Supabase
  participant Y as Yahoo Finance
  B->>S: Buat konteks dengan rule, pasar, tanggal dan horizon
  S->>D: Periksa sesi, entitlement, ownership dan versi rule
  S-->>B: Katalog/rule dibekukan, jumlah batch
  loop Satu batch aktif, maksimal 10 saham
    B->>S: Siapkan batch
    S->>Y: OHLCV harian dengan warmup dan buffer
    S-->>B: Manifest dan content terikat konteks
    B->>B: Go/WASM menghitung indikator dalam worker
    B->>S: Feature vector dan compute grant
    S->>S: Evaluasi rule privat, crossover dan cooldown
    S-->>B: Semua kejadian sinyal
    B->>B: Go/WASM analisis T+n dan TP/SL; simpan detail di IndexedDB
    B->>S: Lepaskan snapshot batch
  end
```

Tidak ada pekerjaan background server setelah browser berhenti. Setiap batch
tetap diperiksa izinnya. Nilai fitur dari browser bukan bukti komputasi yang
tahan manipulasi; Model A bukan DRM. Candle cache historis terenkripsi yang
sudah ada tetap terpisah dari detail turunan studi.

## Ketepatan dan pembanding Claudio

| Aspek | Pembanding/ketentuan | Versi baru |
| --- | --- | --- |
| Basis | Close candle sinyal | Close candle sinyal; semua sinyal independen |
| Hari berikut | Candle berikut yang tersedia | T+1 bukan besok kalender; fixture Jumat–Senin diuji |
| BUY/SELL | Rumus arah dibandingkan pada input beku | SELL adalah analisis arah, bukan transaksi short nyata |
| TP/SL bersamaan | Kebijakan konservatif SL dahulu | Diuji BUY dan SELL |
| Future data kurang | Perilaku legacy dapat memotong horizon | Ditandai incomplete; tidak masuk denominator evaluasi |
| Portofolio | Ada aturan modal/posisi tersendiri | Mode next-open lama dipertahankan terpisah |

`check_signal_study_claudio.py` lulus 24 perbandingan rumus pada sumber dan
input dengan SHA yang dibekukan. Lihat
[baseline](../backend/core/testdata/BACKTEST_BASELINE.md). Ini pembanding
terbatas, bukan klaim parity seluruh aplikasi Claudio. Katalog yang dipakai
adalah katalog aktif saat run, belum point-in-time historis; survivorship bias
dan gap provider harus disebutkan saat menjelaskan hasil.

## Pengujian yang dijalankan

- `go test -race ./...` lulus, termasuk kontrak API 0.15.0, binding owner/sesi,
  perubahan rule, pembatalan, respons terlambat dan retry subset batch beku.
- 205 tes frontend lulus; typecheck dan production build lulus.
- Suite browser workspace/jurnal, keputusan screener, recovery, portofolio,
  Start–Stop monitor dan studi lulus. Studi memakai Go/WASM asli, API/account/
  provider sintetis: 23 saham, 3 batch, 92 sinyal, seluruh horizon dalam CSV,
  paging IndexedDB, retry, quota rollback dan navigasi. Viewport 1440/390 px;
  dark serta forced-light CSS diuji. Forced-light bukan fitur tema baru.
- Native/WASM parity mencakup portofolio lama, 78 keluarga indikator,
  studi BUY/SELL horizon 1/3/100, TP/SL dan data kurang. Private evaluator
  tidak diekspor ke WASM.
- PostgreSQL 17 lokal terpisah: 12 migration dan 3 pemeriksaan kebijakan
  schema lulus; paket API, records, session, universe dan database lulus
  dengan database nyata, termasuk pengujian ownership/RLS yang tersedia.
- Metadata cloud diperiksa baca-saja: 12 migration, terakhir
  `20261027080957 journal_and_backtest_records`; RLS/FORCE RLS
  `signalgen.user_records` aktif. Tidak menjalankan migration cloud baru.
- Preflight lokal lulus: liveness, readiness database/role/schema, API,
  proxy frontend, kecocokan OpenAPI, penolakan tanpa login, JSON 404 dan
  pasangan asset Go/WASM.

Ini tidak menggantikan audit keamanan produksi atau uji seluruh venue saham.
Format global masih memiliki peringatan lama pada lima file di luar perubahan
fitur ini; file tersebut tidak diformat massal.

## Bukti performa dan keterbatasannya

Artefak yang dapat diperiksa:
[native compute](evidence/asis-20261104/native-compute.json),
[HTTP admission](evidence/asis-20261104/http-admission.json),
[browser stages](evidence/asis-20261104/browser-stages.json).

Eksperimen native: Go 1.27.2, darwin/arm64, 10 CPU, input identik 10 saham ×
300 candle, 10 pengulangan. Angka berikut p50/p95 milidetik; admission dibatasi
32 pekerjaan bersamaan. Ini CPU lokal, tanpa Supabase, Yahoo, transfer atau UI.

| Pengguna logis per gelombang | Indikator + rule | Rule saja | Diterima / percobaan total |
| --- | --- | --- | --- |
| 1 | 1.81 / 2.22 | 1.00 / 1.05 | 10 / 10 |
| 10 | 5.98 / 6.99 | 3.22 / 3.89 | 100 / 100 |
| 30 | 13.39 / 16.40 | 7.95 / 10.03 | 300 / 300 |
| 100 | 15.48 / 31.82 | 8.64 / 10.66 | 320 / 1.000 |
| 1.000 | 13.61 / 17.91 | 8.81 / 10.82 | 320 / 10.000 |

CPU evaluasi saja lebih kecil dalam percobaan ini. Representasi JSON fixture
candle 308.093 byte dan fitur 452.581 byte: pemindahan komputasi tidak otomatis
memperkecil transfer. Angka ini bukan seluruh traffic HTTP terkompresi.
Alokasi serta peak heap sampel tercatat di artefak; bukan peak memori seluruh
mesin atau pengukuran RSS browser.

Eksperimen HTTP loopback memakai auth/session/provider sintetis dan batch
pertama saja, bukan 1.000 pengguna produksi:

| Pengguna logis | Konteks diterima / ditolak kapasitas | Snapshot berhasil / gagal kapasitas |
| --- | --- | --- |
| 1 | 1 / 0 | 10 / 0 |
| 10 | 10 / 0 | 100 / 0 |
| 30 | 30 / 0 | 128 / 172 |
| 100 | 32 / 68 | 128 / 192 |
| 1.000 | 32 / 968 | 128 / 192 |

Tidak ada error tak terduga pada permintaan yang diuji. Penolakan kapasitas
bukan keberhasilan screening. Batas konteks 32 dan snapshot global 128 adalah
batas instance sekarang; throughput produksi memerlukan evaluasi lanjutan.

Browser fixture mencatat access, startup WASM, prepare, transfer, grant,
indikator, scoring, analisis, penyimpanan dan React render secara terpisah.
Jaringan sintetis tidak membuktikan latensi Yahoo atau autentikasi cloud.
React Profiler memakai development build, bukan waktu layout/paint seluruh
halaman. Hasil perangkat desktop dengan viewport mobile bukan benchmark ponsel.
Untuk akun asli, ekspor stage JSON dari UI; jangan menganggap stage gabungan
access sebagai waktu database/auth murni.

## Urutan demo

1. Jalankan backend Docker dan frontend pada port **5174**. Jalankan preflight
   di bawah, lalu login sendiri; jangan menampilkan token atau isi `.env`.
2. Screener: pilih universe IDX kecil, interval 5m, Start lalu Stop. Jelaskan
   candle selesai, indikator browser dan rule server; No match adalah hasil sah.
3. Backtesting → Analyse every signal. Mulai dengan universe kecil, rule milik
   akun, tanggal Oktober 2026, n=3, TP=5%, SL=3%. Tunjukkan progres/cakupan,
   semua horizon, detail dan CSV. Nol sinyal bukan demonstrasi TP/SL.
4. Untuk bukti hasil yang pasti, gunakan fixture teruji 23 saham/92 sinyal;
   label sebagai fixture. Jangan mengubah kondisi rule tanpa menjelaskan
   bahwa itu rule demonstrasi, bukan rekomendasi investasi.
5. Ulangi AS terpisah dalam USD. Seluruh katalog dapat dipilih, tetapi jangan
   menjanjikan demo jaringan ribuan saham akan selesai pada waktu tertentu.
6. Jurnal: tampilkan alur manual dan checklist → review → konfirmasi. Tidak
   perlu menyimpan transaksi palsu ke akun asli; gunakan fixture untuk retry.
7. Tunjukkan tabel Claudio, bukti performa dan batas di atas. Cadangan jaringan:
   screenshot fixture dan CSV yang diekspor saat tes, berlabel sintetis.

```sh
# Dari root repository
node backend/scripts/demo_preflight.mjs http://127.0.0.1:8080 http://localhost:5174
# Dari frontend/web
npm test
npm run build
npm run test:study
# Dari backend
go test -race ./...
python3 scripts/check_signal_study_claudio.py
```

## Smoke test layanan asli — 2 November

Login akun asli, backend lokal dan Supabase cloud berhasil. Universe IDX
ASII/ANTM/INDF, rule milik akun “Test”, 1–31 Oktober 2026, n=3, TP5/SL3:
**3/3 saham selesai, 0 gagal, 0 sinyal**. Ini membuktikan alur data/izin dan
hasil tanpa sinyal, bukan pembuktian profit atau TP/SL dari pasar asli.
Universe AS milik akun, rule dan konfigurasi yang sama: **10/10 saham selesai,
0 gagal, 0 sinyal**, pasar US/USD. Kedua sampel selesai melalui UI akun asli.
Kasus sinyal positif, perhitungan return dan TP/SL dibuktikan terpisah dengan
fixture beku; tidak diklaim terbukti oleh dua sampel tanpa sinyal tersebut.

## Yang masih perlu ditindaklanjuti

- Smoke test seluruh katalog dengan laporan coverage dan kegagalan provider;
  jangan menyebut seluruh pasar selesai berdasarkan fixture tiga batch.
- Pengukuran cloud auth/database yang terpisah dan perangkat ponsel fisik;
  pengujian kapasitas produksi termasuk replica/context lifecycle.
- Verifikasi operasional lagi sebelum asis Rabu: data Yahoo dan koneksi
  Supabase dapat berubah setelah hasil uji Senin.
- Konfirmasi kebijakan data point-in-time, gap historis dan hak pemakaian data
  sebelum menjanjikan penelitian bebas bias atau penggunaan komersial.
