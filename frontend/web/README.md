# SignalGen Web Frontend

Konteks dan arsitektur kanonis tersedia di
[`../../PROJECT_CONTEXT.md`](../../PROJECT_CONTEXT.md). Baca dokumen tersebut
sebelum melakukan scaffold.

Folder ini disiapkan untuk landing page dan portal web SignalGen.

Ruang lingkup yang direncanakan:

- Landing page dan informasi produk.
- Pricing dan checkout.
- Login serta pengelolaan akun.
- Status dan pengelolaan subscription.
- Download aplikasi desktop.

Toolchain JavaScript belum diinisialisasi agar tim frontend dapat memilih
framework dan package manager tanpa membawa keputusan sementara dari backend.
